Installazione & Generatore APK

Opzione 1: Installa direttamente su Android (PWA)

Apri questa pagina con Google Chrome sul tuo smartphone Android, tocca il menu in alto a destra (i tre puntini ⋮) e seleziona "Aggiungi a schermata Home" o "Installa app". L'app si aprirà a schermo intero come una vera app nativa.

Opzione 2: Generare il file .APK per il progetto scolastico

Poiché questa applicazione è un file singolo autonomo, puoi generare l'effettivo file installabile .apk in 1 minuto:

  1. Salva questo codice sul tuo computer come file index.html.
  2. Vai sul sito gratuito PWABuilder.com (oppure usa Website 2 APK Builder).
  3. Carica la pagina o inserisci il link di pubblicazione (es. GitHub Pages / Netlify).
  4. Clicca su "Generate APK" per scaricare direttamente sul telefono il pacchetto .apk pronto per la verifica.
